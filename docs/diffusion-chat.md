# Консольный diffusion-чат

`kinetic diffuse-chat` — интерактивный CPU-интерфейс для явно помеченных
diffusion GGUF LFM2 MoE. Проверен на существующей уменьшенной FP32-модели.
Полные веса 24B не загружались. Текущая модель не обучена: её ответы —
случайный текст; в шапке это явно отмечено.

## Запуск на этой машине

Двойной щелчок по `D:\LLM\start-diffusion-chat.cmd` открывает готовый чат.
Бинарь: `D:\LLM\kinetic-diffusion-chat-cpu.exe`.
Предыдущие CPU-бинарники и основной CUDA launcher не заменены.

```powershell
& D:\LLM\kinetic-diffusion-chat-cpu.exe diffuse-chat `
  D:\LLM\models\lfm25-diffusion-cpu-fixture\lfm2moe-diffusion-fixture-f32.gguf `
  --mask-embedding D:\LLM\models\lfm25-diffusion-cpu-fixture\mask.safetensors `
  --threads 6
```

По умолчанию: canvas 16, 4 прохода на блок, максимум 64 новых токена,
окно добавляемой истории 128 токенов, prefix reuse включён.
`--no-prefix-reuse` оставляет полный пересчёт для сравнения.

## Работа в терминале

- Цветные заголовки диалога, редактирование строки и история ввода
  стрелками вверх/вниз. История ввода хранится только в памяти процесса.
- Во время подготовки и до первых окончательных символов — вращающийся
  индикатор и шкала заполнения canvas с номером блока/прохода.
- Ответ постепенно появляется из **закоммиченного непрерывного начала**
  canvas. Позиции за незаполненным участком и предварительные догадки не
  показываются. UTF-8 декодируется потоком через существующий StreamDecoder.
- Markdown форматируется штатным renderer Kinetic: заголовки, списки,
  код и таблицы. Управляющие символы модельного текста не исполняются терминалом.
- `Ctrl+C` останавливает расчёт или анимированное проявление текста и
  возвращает ввод. Прерванный ход не добавляется в историю диалога.
  `Ctrl+D`, `/exit` и `/quit` завершают чат.
- В конце ответа показываются число токенов, проходов и время ответа
  вместе с визуальным выводом. Это не измерение чистой скорости инференса.

Команды:

| Команда | Действие |
|---|---|
| `/help` | Показать команды |
| `/clear` | Новый диалог с сохранением системных инструкций |
| `/settings` | Показать параметры |
| `/canvas N` | Позиции canvas, 1–64 |
| `/steps N` | Проходы на блок, 1–16 |
| `/tokens N` | Лимит ответа, 1–256 |
| `/reuse on` / `/reuse off` | Prefix reuse / полный пересчёт |
| `/system ТЕКСТ` | Новые инструкции и сброс диалога |
| `/system` | Убрать системные инструкции и начать заново |
| `/raw` | Переключить показ Markdown без форматирования |

Если история перестаёт помещаться, удаляются только самые старые полные
пары user/assistant. Системное сообщение и текущее сообщение сохраняются;
о сокращении контекста выводится сообщение. Слишком длинное отдельное
сообщение отклоняется с предложением его укоротить; чат продолжает работу.
Это отдельная история диалога, не `prefix_window` истории внутри одного ответа.

Берётся `tokenizer.chat_template` из GGUF. У тестовой модели его нет,
поэтому используется простой текстовый шаблон `user: …\nassistant: …`.
Никакой скрытой подмены ответа обученной AR-моделью нет.

`--pace-ms 2` задаёт задержку отображения символа (0–30 мс), не меняя
сэмплер. `--no-animation` сохраняет цвета/Markdown без задержки и индикатора.
`--plain` и перенаправленный ввод/вывод отключают ANSI и анимацию;
`--plain` также использует обычный построчный ввод вместо редактора.
Переменная `NO_COLOR` отключает цвета и визуальные эффекты.
Launcher можно вызвать с `--plain` или `--no-animation`.

## Проверки

Три unit-теста проверяют границы стабильного участка canvas/EOS, сокращение
истории целыми парами и удаление управляющих символов с сохранением Unicode.
GGUF integration-тест сравнивает отображённые ответы с независимыми
одиночными diffusion-запусками: первый ход, второй ход с историей, `/clear`
и повтор первого хода; также проверяет отказ для `/canvas 0`, сохранение
настроек и отсутствие ANSI при перенаправлении.

```powershell
$env:KINETIC_TEST_DIFFUSION_GGUF='D:\LLM\models\lfm25-diffusion-cpu-fixture\lfm2moe-diffusion-fixture-f32.gguf'
cargo test --locked --release -p kinetic-cli --no-default-features --test diffusion_chat -- --ignored
```

Живой терминальный прогон проверяет русский ввод, цвета, плавный вывод и
возврат приглашения. Отдельно проверено прерывание Ctrl+C во время проявления
текста и следующий успешный ответ в том же чате. `NO_COLOR=1` окружения Codex
для этого снят только в отдельном тестовом процессе. Новые зависимости не добавлены.
